# Exclusive - E-Commerce Platform

A modern e-commerce platform built with microservices architecture.

## 🎯 About

Exclusive is an e-commerce platform designed to provide a scalable and maintainable solution for online retail operations.

## 🛠️ Tech Stack

- **Backend**: Java, Spring Boot
- **Frontend**: React
- **Database**: MySQL
- **Containerization**: Docker

## 📁 Project Structure

```
Exclusive/
├── microservices/     # Backend microservices
├── frontend/         # Frontend applications
└── docker-compose.yml
```

## 🚀 Getting Started

### Prerequisites

- Java 21
- Maven
- Docker and Docker Compose
- Node.js and npm

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd EcomMicro
```

2. Build the project
```bash
mvn clean install
```

3. Run with Docker
```bash
docker compose up
```
